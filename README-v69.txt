Ventra v69 — اصلاح احراز هویت همگام‌سازی 3D، پچ تجمیعی

تمام فایل‌های پچ v68 نیز در این ZIP هستند. این فایل پروژه کامل نیست؛ محتویاتش را در ریشه پروژه موجود کپی و فایل‌های هم‌نام را جایگزین کنید. .env.local را نگه دارید. SQL جدید لازم نیست.

اصلاح جدید: درخواست GET و PUT مسیر /api/project-3d-state اکنون توکن حساب واردشده را می‌فرستد. کنترل مالکیت پروژه در سرور حفظ شده است. کلید خصوصی جدیدی در مرورگر قرار نمی‌گیرد.

روش انتشار در PowerShell، در همان پوشه‌ای که package.json است:
git status
git add src/lib/commercialFetch.js tests/cloud-3d-auth.test.mjs README-v69.txt
اگر تغییرات پچ‌های قبلی هنوز commit نشده‌اند، فایل‌های آن‌ها را نیز پس از بررسی git status اضافه کنید. کلیدها و .env.local را commit نکنید.
git commit -m "Fix authenticated 3D cloud synchronization"
git push origin main
در Netlify منتظر انتشار موفق همین commit بمانید.

انتقال مدل قبلی: روی کامپیوتری که مدل در آن موجود است، نسخه اصلاح‌شده را اجرا کنید و با همان حساب پروژه را در تب 3D باز کنید. اگر مدل قبلاً روی localhost ساخته شده، ابتدا روی همان localhost به‌روز‌شده بازش کنید؛ باز کردن Netlify به‌تنهایی اطلاعات localStorage یا IndexedDB localhost را منتقل نمی‌کند. Supabase محلی و Netlify باید یک پروژه یکسان باشند.
در Network بررسی کنید GET /api/project-3d-state و PUTهای انتقال مدل پاسخ 200 داشته باشند. سپس روی گوشی با همان حساب و همان پروژه، نسخه منتشرشده را باز کنید. GET باید schematic یا engineering داشته باشد، نه فقط {}. این تست زنده روی دستگاه شما لازم است؛ در این محیط تست واقعی iPhone/Netlify انجام نشده است.

اگر ذخیره ابری خطا داد، پاسخ همان درخواست را بررسی کنید. وجود bucket project-files، مجوزها و تنظیمات Supabase روی Netlify باید صحیح باشد. خرید دامنه این خطاها را رفع نمی‌کند. برای این تست دوباره تحلیل پولی انجام ندهید.

اتصال دامنه تغییر جداگانه‌ای است و به نام دامنه، تنظیمات Netlify و DNS نیاز دارد. این پچ دامنه‌ای را متصل نمی‌کند.
