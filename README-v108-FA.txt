پچ v108 — هندسه جزئی مستقل برای مساحت‌های PDF

این پچ را روی پروژه دارای v107 نصب کنید. فایل‌های پوشه src و tests را در همان مسیرهای پروژه جایگزین کنید؛ پوشه src را داخل src دیگری نگذارید.
هیچ SQL، تغییر env یا وابستگی جدید لازم نیست. فایل .env.local خود را نگه دارید.

علت خطای گزارش (6):
هندسه همکف کامل بود، اما مدل هندسه طبقه اول را به دلیل نبود ابعاد بعضی تیغه‌ها null گذاشته بود. در v107 همه هندسه لازم بود؛ بنابراین راهروی قابل اندازه‌گیری نیز کنترل نمی‌شد و سرامیک کل کنار گذاشته می‌شد. عدد ۲۴ این بار در گزارش خوانده شده است ولی هندسه مستقل آن ذخیره نشده است.

تغییر:
- قرارداد تحلیل اکنون complete/partial را جدا می‌کند. نبود ابعاد یک اتاق نباید باعث حذف چندضلعی راهروی اندازه‌دار شود.
- تمام مساحت‌های استنباطی برای پذیرش نیاز به چندضلعی مستقل با ابعاد دارند.
- در حالت partial، سایر اتاق‌ها فقط با تگ یکتا، مصالح مشخص و مساحت صریح چاپ‌شده پذیرفته می‌شوند؛ جمع آن‌ها نیز باید با پوسته سازگار باشد.
- این حالت در گزارش و UI «هندسه بخش‌های اندازه‌دار + برچسب نقشه» مشخص می‌شود، نه تأیید کامل هندسه ساختمان. مقدارهای آن هنوز تخمینی و نیازمند بازبینی‌اند.
- تداخل، خروج از پوسته، تگ تکراری، مساحت استنباطی بدون هندسه یا ناقص‌بودن جمع باعث کنارگذاشتن مقدار می‌شود. هیچ عدد ویژه‌ای برای پروژه تست در کد برنامه قرار نگرفته است.

پس از نصب:
۱. npm run build
۲. برای استفاده آنلاین، تغییرات را commit و push کنید و صبر کنید Deploy جدید Netlify Published شود.
۳. در Drawings همان PDF را یک بار Analyze کنید؛ این مرحله API مصرف می‌کند. گزارش قدیمی هندسه null دارد و با Generate BOQ تنها، ابعاد تازه ایجاد نمی‌شود.
۴. سپس Generate BOQ را اجرا کنید و گزارش تحلیل جدید و خروجی BOQ را برای کنترل بفرستید.
اگر مدل هنوز هیچ هندسه مستقلی ندهد، مقدار نامطمئن همچنان pending می‌ماند؛ پچ آن را به اجبار قیمت‌گذاری نمی‌کند.

اعتبارسنجی:
۵۳۶ تست موفق، production build موفق، بیلد پردازشگر Netlify موفق، قرارداد strict JSON بررسی شد.
تست بازپخش با تزریق چندضلعی مستقل راهرو: سرامیک طبقه اول ۴۶ و کل ۱۵۴ مترمربع؛ جمع کف ۳۷۲ و سقف ۳۶۰. تزریق فقط در تست است و در برنامه اجرا نمی‌شود.
اجرای زنده OpenAI/Netlify شما توسط ما انجام نشده است؛ نتیجه واقعی باید با گزارش تازه کنترل شود.

محدوده:
این پچ استخراج مساحت PDF را اصلاح می‌کند. نرخ و مشخصات نامعلوم، قالب‌بندی، بنایی و سایر ردیف‌های pending به‌خودی‌خود تکمیل نمی‌شوند. جمع فعلی فایل (11) هزینه کامل پروژه نیست.
