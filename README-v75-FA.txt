Ventra v75 — DWG view loading, early reconstruction geometry, bounded AI schedule review
Includes v73 + v74 changes.

لاگ شما سه مورد مشخص دارد:
1) os error 112 / There is not enough space on the disk.
   این خطا روی لپ‌تاپ ویندوز است و به کش Turbopack مربوط می‌شود. خرید دامنه یا تغییر کد آن را حل نمی‌کند.
2) The Autodesk model does not contain viewable geometry.
   SDK مدل را گرفته ولی هندسهٔ پیش‌فرض ندارد. موفق بودن job به‌تنهایی وجود مدل قابل نمایش را ثابت نمی‌کند.
3) dwg-evidence درخواست‌های ۲ دقیقه و ۲۴ ثانیه و ۵۳ ثانیه داشته است.
   برنامه دو خواندن مستقل جدول‌ها را پشت‌سرهم انجام می‌داد و ذخیرهٔ هندسهٔ نهایی را تا پایان آن عقب می‌انداخت.

تغییرات:
- انتخاب نمای قابل بارگذاری DWG از search یا درخت Model/layout؛ وابستگی صرف به getDefaultGeometry حذف شد.
- برای استخراج DWG نمای دوبعدی موجود اولویت دارد؛ مدل اصلی از بین نمی‌رود.
- تبدیل success بدون نمای هندسی بعد از دو بررسی مجدد با خطای روشن متوقف می‌شود؛ نتیجهٔ آمادهٔ کاذب ایجاد نمی‌شود.
- هندسهٔ دیوار و مقیاس معتبر پیش از تحلیل تکمیلی اتاق/جدول در رکورد engineering ذخیره می‌شود و برای 3D قابل استفاده است.
  این ذخیرهٔ اولیه، BOQ یا شمارش اتاق‌های تکمیل‌نشده را آمادهٔ نهایی اعلام نمی‌کند.
- نتیجهٔ مربوط به فایل دیگری قبل از شروع تحلیل پرهزینه رد می‌شود.
- دو خواندن مستقل جدول هم‌زمان اجرا می‌شوند؛ سقف انتظار ۶۰ ثانیه و بدون retry خودکار OpenAI هستند.
  اگر به سقف برسند، مقادیر جدول تأییدشده محسوب نمی‌شوند؛ هندسهٔ مستقل از آن قابل نمایش می‌ماند.
- دکمهٔ Reconstruct 3D از More tools به نوار اصلی منتقل شده است؛ هیچ دکمهٔ قبلی حذف نشده.
- متغیر اختیاری VENTRA_DISABLE_DEV_CACHE=1، نوشتن کش فایل سیستم Turbopack در توسعه را خاموش می‌کند.
  این حالت به فضای دیسک همچنان نیاز دارد و شروع مجدد توسعه را می‌تواند کندتر کند.

اول فضای دیسک را اصلاح کنید:
در ترمینالی که npm run dev اجراست، Ctrl+C بزنید.
از تنظیمات Storage ویندوز یا جابه‌جایی فایل‌های بزرگ شخصی چند گیگابایت فضا آزاد کنید.
در ریشهٔ پروژه ونترا، این فرمان PowerShell را اجرا کنید:
Remove-Item -LiteralPath '.next' -Recurse -Force
این فرمان فقط خروجی و کش تولیدشدهٔ Next را حذف می‌کند. src یا .env.local را حذف نکنید.
اگر خطای فایل در حال استفاده گرفتید، ابتدا سرور توسعه را کامل متوقف کنید.

نصب:
پوشه src پچ را با src پروژه ادغام کنید، و next.config.mjs را در ریشه جایگزین کنید.
src نباید داخل src دیگری قرار بگیرد. این پچ SQL جدید ندارد.
npm run dev
برای Netlify: تغییرات را commit/push کنید و منتظر Deploy موفق جدید بمانید.
اگر به‌طور موقت نوشتن کش را نمی‌خواهید، در ترمینال PowerShell قبل از اجرای dev:
$env:VENTRA_DISABLE_DEV_CACHE='1'
npm run dev

آزمایش:
1. Drawings: همان DWG را انتخاب و یک بار Analyze کنید. وضعیت ترجمه و خطاها را ببینید.
2. اگر پیغام هندسهٔ قابل نمایش ندارد باقی ماند، محتوای Model/Layout فایل باید بررسی شود؛
   این پچ فایل DWG خالی/خراب یا تبدیل Autodesk بدون هندسه را به یک ساختمان خیالی تبدیل نمی‌کند.
3. برای نقشهٔ دوبعدیِ دارای دیوارهای معتبر، مقیاس را از واحد/بعد معلوم تأیید کنید و استخراج را کامل کنید.
4. در 3D، DWG / Engineering و سپس Reconstruct 3D را بزنید. دکمه روی نوار اصلی است.
5. پس از بازسازی، هر محدودهٔ پلان را جدا انتخاب کنید، نوع اتاق‌های بی‌نام را مشخص کنید و Furnish and save را بزنید.

حدود تأیید:
تست‌های انتخاب نمای 2D بدون default، درخت fallback، نتیجهٔ بدون هندسه، رد callback فایل دیگر،
و اجرای موازی/timeout دو خواندن اجرا شده‌اند. تست‌ها و build کل پروژه نیز انجام شده است.
BOQ بعد از موفقیت استخراج نهایی همچنان باید با نقشه بازبینی شود.
لاگ شما از وسط متن shader شروع شده؛ علت خطای احتمالی GPU از این بخش قابل تعیین نیست.
اگر صفحه هنوز سفید/سیاه بود، ابتدای خطای Console شامل THREE.WebGLProgram/ERROR را ارسال کنید.
DWG اصلی، Autodesk زنده و گوشی شما در این محیط برای این نسخه آزمایش نشده‌اند.
