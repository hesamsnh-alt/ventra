Ventra v76 — اصلاح انتخاب DWG و بازیابی هندسه

این پچ شامل فایل‌های اصلاح‌شدهٔ v73 تا v75 و اصلاح تازهٔ v76 است.
نیازی به SQL تازه ندارد.

اصلاح مشخص:
- بازیابی ابری دیگر DWG قدیمی را روی DWG تازه‌تر محلی نمی‌نویسد.
- بعد از دریافت پاسخ شبکه، اطلاعات محلی دوباره خوانده می‌شود تا آپلود جدید حین انتظار از بین نرود.
- URN مدل و هندسه از یک رکورد انتخاب می‌شوند؛ دادهٔ دو فایل مختلف ترکیب نمی‌شود.
- رویداد استخراج فایل جدید، منبع نمایشگر را هم به همان فایل جدید تغییر می‌دهد.
- دکمه‌های بارگذاری هندسه و باز کردن Drawings ظاهر واضح و اندازهٔ مناسب لمس دارند.

نصب:
1. با Ctrl+C سرور را متوقف کنید. محتوای زیپ را در ریشهٔ ventra ادغام و فایل‌های هم‌نام را جایگزین کنید؛ پوشهٔ src نباید داخل src دیگری قرار بگیرد.
2. npm run dev را اجرا کنید و مرورگر را با Ctrl+Shift+R تازه کنید.
3. در همان پروژه تب 3D را باز کنید و «Load saved geometry and reconstruct» را بزنید.

تأیید نتیجه:
توکن APS باید برای همان DWG تازهٔ انتخاب‌شده درخواست شود، نه مدل قدیمی.
اگر پیام «DWG scale is not available yet» باقی ماند، بازسازی متوقف می‌ماند؛ مقیاس ساختگی یا هندسهٔ فایل دیگر استفاده نمی‌شود. پیام دقیق و گزارش استخراج Drawings برای تشخیص بعدی لازم است.

آزمون: 371 تست خودکار و بیلد تولید موفق. فایل DWG واقعی این پروژه در محیط بررسی موجود نبود؛ بازسازی واقعی آن هنوز تأیید نشده است.
