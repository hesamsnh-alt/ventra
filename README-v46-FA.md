# Ventra v46 — رندر تصویری و تشخیص فضای چندزبانه

## نصب
فایل کامل را در پوشه جدید باز کنید. .env.local خودتان را در ریشه ventra نگه دارید؛ فایل بسته شامل کلید نیست. npm ci و سپس npm run dev اجرا کنید. اگر دیتابیس v44 را قبلاً کامل نصب کرده‌اید، SQL تازه‌ای لازم نیست.

## استفاده
در صفحه پروژه، تب 3D، پنل «رندر واقعی طراحی» را باز کنید. تصویر اصلی JPG/PNG/WebP تا ۵ مگابایت را انتخاب کنید، سبک مدرن/مینیمال/لوکس و توضیحات فارسی یا عربی را وارد کنید و «تولید رندر واقعی» را بزنید. هر کلیک درخواست پولی OpenAI و یک مصرف از سهمیه تحلیل دارد؛ تولید خودکار یا retry خودکار ندارد. گزینه پیشنهاد دوش تنها زمانی آن را پیشنهاد می‌کند که جا داشته باشد؛ در WC کوچک نباید اجباراً دوش ساخته شود.

رندر یک تصویر پیشنهادی قابل دانلود است، نه مدل قابل‌چرخش. روی همین مرورگر/دستگاه در IndexedDB ذخیره می‌شود؛ بین دستگاه‌ها همگام نمی‌شود. هندسه، BOQ و مقادیر مهندسی با آن عوض نمی‌شوند. از این تصویر برای متره استفاده نکنید.

کلید OPENAI_API_KEY موجود استفاده می‌شود. مدل پیش‌فرض chatgpt-image-latest است؛ OPENAI_PLAN_RENDER_MODEL اختیاری است. اگر حساب API دسترسی به مدل تصویر ندارد، خطا نمایش داده می‌شود و تصویر ساختگی یا مدل ساده جایگزین ارائه نمی‌شود. هاست باید زمان کافی برای درخواست رندر داشته باشد (حداکثر درخواست ۲۴۰ ثانیه؛ route maxDuration=300).

## تشخیص فضای فارسی و عربی
تراس/بالکن/ایوان/شرفة و سرویس/حمام/دستشویی/دورة المياه دسته‌بندی می‌شوند. این تغییر فقط نام‌ها و typeهای موجود را دسته‌بندی می‌کند؛ اگر AI اصلاً فضای تراس را در هندسه استخراج نکرده باشد، آن را از هیچ نمی‌سازد. برای اثر روی مدل قبلی، تصویر را دوباره Analyze کنید. نام اصلی فضای مشتری حفظ می‌شود.

## بررسی‌ها و محدودیت‌ها
۲۱۹ تست موفق؛ lint فایل‌های تغییرکرده و build production موفق. تست‌ها ورودی، یک‌بار فراخوانی، نبود retry، عدم موفقیت ساختگی، برچسب‌های چندزبانه و پنل واقعی سه‌زبانه را بررسی می‌کنند. درخواست واقعی پولی در این محیط اجرا نشده است؛ کیفیت رندر، صحت کامل پلان و امکان دسترسی حساب API شما هنوز تأیید نشده‌اند. خروجی دقیقاً مشابه ChatGPT تضمین نشده است.

اصلاح زبان نمایشگر و غیرفعال‌سازی Hyperlink از بسته قبلی هم در این نسخه وجود دارد. علت کامل خطاهای واقعی Autodesk هنوز با manifest نقشه باید بررسی شود.
