# اصلاح چت راهنمای ونترا

فایل‌های ZIP را داخل پوشه اصلی ventra، کنار package.json، کپی و فایل‌های هم‌نام را جایگزین کن. سرور را متوقف و npm run dev را دوباره اجرا کن. مرورگر را با Ctrl+Shift+R تازه‌سازی کن.

## استفاده

Help پایین صفحه پنجره گفت‌وگو را باز می‌کند. در /support همین گفت‌وگو همیشه باز است. سؤال را بنویس و Send را بزن یا یک موضوع را انتخاب کن.

دو حالت وجود دارد:
- Quick guide / راهنمای آماده: پاسخ‌های محصول، بدون ورود و بدون API.
- Ask AI / پرسش از AI: سؤال آزاد و پیام‌های اخیر برای پاسخ‌گویی به OpenAI ارسال می‌شوند. کاربر باید وارد حساب شود. کلید OPENAI_API_KEY موجود در .env.local سرور استفاده می‌شود. کلید را در کادر چت ننویس. OPENAI_HELP_MODEL اختیاری است و پیش‌فرض gpt-4.1-mini است.

چت به اطلاعات پروژه و وضعیت واقعی پرداخت دسترسی ندارد و پروژه را تغییر نمی‌دهد. پاسخ AI باید بررسی شود. اگر AI تنظیم نشده یا سرویس خطا بدهد، خطای قابل مشاهده همراه با راهنمای آماده نمایش داده می‌شود. کلیک روی موضوعات، همیشه پاسخ آماده می‌دهد.

بازشدن پنجره از عنصر native details/summary استفاده می‌کند و به اجرای onClick وابسته نیست. ارسال پیام نیازمند JavaScript است. گفت‌وگو با refresh پاک می‌شود.

API فقط کاربران تأییدشده Supabase را می‌پذیرد. سقف ۳۰ تلاش AI در ۲۴ ساعت و یک درخواست هم‌زمان برای هر کاربر، در حافظه همان فرآیند سرور است؛ با restart پاک می‌شود و در چند سرور مشترک نیست. برای انتشار چندسروری محدودیت مشترک باید اضافه شود. درخواست‌های مدل retry خودکار ندارند و store:false دارند. هزینه هر درخواست مطابق حساب OpenAI است.

نیازی به migration یا نصب وابستگی جدید نیست. فایل‌های هندسه، مدل‌سازی، BOQ و پرداخت در این پچ دستکاری نشده‌اند.

## کنترل

آزمون پاسخ‌ها، زبان‌ها، لینک‌ها و اعتبارسنجی ورودی AI اجرا می‌شود. تست مرورگر به دلیل رد مجوز انجام نشد. پاسخ زنده OpenAI و ورود واقعی حساب در این محیط تست نشده‌اند؛ درخواست پولی آزمایشی ارسال نشده است. ساخت محلی با Next.js نصب‌شده 16.2.10 و webpack بررسی می‌شود، نه نسخه 16.3.8 سیستم شما.
