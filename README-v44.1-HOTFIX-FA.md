# Ventra v44.1 — رفع خطاهای گزارش‌شده

این بسته پروژهٔ کامل v44 به همراه اصلاح دو خطای اجرایی است.

برای ارتقای v44، فقط این دو فایل اجرایی را از بسته جایگزین کنید:

- src/app/components/i18n/LocalizedElement.jsx
- src/app/components/ApsViewer.jsx

سپس سرور را با Ctrl+C ببندید، npm run dev را اجرا کنید و صفحهٔ پروژه را با Ctrl+Shift+R بارگیری کنید. فایل .env.local، داده‌های پروژه و دیتابیس را تغییر ندهید. نصب SQL تازه برای این ارتقا لازم نیست.

## رفع‌شده

- خواندن length از undefined در LocalizedElement هنگام نمایش textarea بدون فرزند. فیلدهای کنترل‌شدهٔ پرامپت سه‌بعدی و شرایط پرداخت دیگر با این خطا کرش نمی‌کنند. متن اصلی فیلد و ترجمهٔ placeholder حفظ می‌شود.
- ReferenceError برای loadedDocument در استخراج DWG. نام نمای بارگیری‌شده از currentViewName که در همان محدوده در دسترس است خوانده می‌شود.

سه تست بازگشت اضافه شد: textarea در هر سه زبان، انواع معتبر فرزندان عناصر حفاظت‌شده، و اجرای درخواست متادیتا پس از پایان بلوک بارگیری سند برای هر دو نمای 2D/3D. مجموع تست‌ها: ۲۰۸ موفق، صفر شکست و صفر ردشده. ساخت production با Next.js 16.3.8 و webpack موفق بود.

## موارد حل‌شده اعلام نمی‌شوند

Failed to fetch یک خطای ارتباطی است. در لاگ شما توقف/راه‌اندازی مجدد سرور هم وجود دارد؛ این می‌تواند ارتباط درخواستِ درحال‌اجرا را قطع کند، ولی علت دقیق از همین لاگ قابل اثبات نیست. هنگام اجرای تحلیل طولانی سرور را نبندید.

برای removeChild فقط یک پیام بدون stack کامل داریم؛ رفع مستقل آن اثبات نشده است. اگر پس از نصب این اصلاح و بارگیری کامل دوباره رخ داد، stack کامل لازم است.

ترجمهٔ کامل برنامه همچنان ناتمام است؛ این اصلاح ترجمه‌های باقی‌مانده را تکمیل نمی‌کند. راهنمای عمومی نصب نسخهٔ پایه: README-START-HERE-FA.md.
