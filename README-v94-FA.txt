Ventra v94 — جزئیات مبلمان و خروجی واضح‌تر

شامل پچ‌های v89 تا v93 نیز هست. فایل‌ها با حفظ مسیرها روی ریشه پروژه جایگزین شوند.

تغییرات جدید:
- کوسن‌ها، دسته و پشتی مبل با حجم گرد و نرمال نرم‌تر ساخته می‌شوند، به جای شکل قبلی که هنوز مکعبی دیده می‌شد.
- رنگ پیش‌فرض پارچه مبل، بدون رنگ سفارشی، طبیعی‌تر و خنثی‌تر است.
- گیاه 36 برگ دارد و پرتر است.
- لباسشویی در گرد، حلقه، پنل و کنترل دارد.
- رندر دسکتاپ از render target با MSAA چهار نمونه برای صاف‌تر شدن لبه‌ها استفاده می‌کند.
- خروجی JPG کوچک از مدل دوباره رندر می‌شود تا ضلع بلند 2048 پیکسل؛ بعد رزولوشن و دوربین نمای تعاملی بازیابی می‌شوند. این بزرگ‌کردن ساده تصویر قبلی نیست.
- هندسه ساختمان، مختصات اصلی مبلمان و رفتار ویرایش تغییری نمی‌کنند.

محدودیت واقعی:
این خروجی هنوز فوتورئال یا V-Ray نیست. مدل‌های رویه‌ای مبلمان و بافت‌های تولیدشده ساده‌اند. رسیدن به کیفیت عکس نیازمند کتابخانه مدل مبلمان دقیق و بافت PBR باکیفیت، و احتمالاً رندر آفلاین است.
حالت دیوار شفاف برای دیدن داخل ساختمان است؛ طبیعی است که خروجی آن شبیه یک خانه واقعی با دیوارهای مات نباشد. برای عکس طبیعی‌تر، حالت نمای داخلی/دیوار شفاف را خاموش کنید و از دوربین داخل اتاق استفاده کنید.

نصب در پوشه ventra:
npm install
npm run build

سپس commit و push برای انتشار Netlify.
SQL یا متغیر محیطی جدید لازم نیست. تحلیل دوباره لازم نیست؛ مدل ذخیره‌شده را دوباره باز کنید.

اعتبارسنجی:
468 تست پاس شد و بیلد تولید موفق بود.
خروجی WebGL مسیر دسکتاپ و موبایل، ذخیره JPEG، حفظ داده هندسه و آزاد شدن منابع پیش‌نمایش موقت بررسی شد.
تست خروجی بزرگ‌تر، بازگشت رزولوشن canvas و ثابت ماندن دوربین نیز پاس شد.
