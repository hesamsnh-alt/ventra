Ventra v96 — مدل آماده واقعی و بافت عکاسی‌شده

این پچ شامل v89 تا v95 نیز هست. فایل‌ها را با حفظ مسیر روی ریشه پوشه ventra جایگزین کنید؛ پوشه public/realistic-assets نیز ضروری است و باید به GitHub و Netlify منتقل شود.

تغییر این نسخه صرفاً تنظیم نور نیست:
- مبل حالت پیش‌فرض/کلاسیک و لوکس: مدل آماده Sofa 02 با جزئیات چرمی و بافت PBR.
- صندلی معمولی ناهارخوری: مدل آماده Dining Chair 02 با نشیمن و پشتی چرمی.
- گیاه آپارتمانی: مدل آماده Potted Plant 02 با برگ‌ها و گلدان بافت‌دار.
- کف‌های warm_oak در سبک پیش‌فرض: بافت واقعی Wood Floor، شامل رنگ، زبری و نرمال. سبک‌های دیگر کف و سرامیک تغییر نمی‌کنند.
- حالت مدرن و مینیمال مبل مدل قبلی را حفظ می‌کند؛ مبل چرمی کلاسیک به‌اجبار جایگزین سبک مدرن نمی‌شود.

مدل‌های آماده از Poly Haven و دارای CC0 هستند. منبع و سازنده در public/realistic-assets/CREDITS.txt ثبت شده است.
تمام فایل‌ها محلی روی سایت شما میزبانی می‌شوند. در زمان استفاده، تماس با API Poly Haven یا هزینه OpenAI جدید وجود ندارد.
بافت‌ها 1K هستند تا حجم و مصرف حافظه مناسب‌تر باشد. کل دارایی‌های اضافه حدود 5.5 MB است.

حفظ رفتار:
مدل‌ها فقط در لایه رندر جایگزین می‌شوند. داده پلان و اندازه/مکان مبلمان تغییر نمی‌کند.
اندازه مدل آماده با ابعاد ثبت‌شده همان مبلمان تطبیق می‌یابد و به زمین متصل می‌شود.
چرخش و تغییر اندازه پیش‌نمایش به مدل واقعی منتقل می‌شود. انتخاب از طریق هندسه پروکسی قبلی انجام می‌شود.
اگر دانلود دارایی از سایت خودتان شکست بخورد، مدل قبلی باقی می‌ماند.
ذخیره JPG برای بارگذاری دارایی‌ها حداکثر 15 ثانیه منتظر می‌ماند؛ بعد خروجی آماده فعلی را ذخیره می‌کند.

محدودیت صریح:
این نسخه به معنی فوتورئال شدن تمام پروژه یا رسیدن به V-Ray نیست. تخت، کابینت، میز، در و بسیاری از وسایل هنوز مدل ساده دارند. رندر فعلی real-time است و path tracing آفلاین ندارد.
مبل واقعی افزوده‌شده چرمی و کلاسیک است؛ این یک مدل جدید است و ظاهر پارچه‌ای قبلی را عیناً بازسازی نمی‌کند.

نصب در پوشه ventra:
npm install
npm run build

بعد از موفق شدن build، commit و push کنید؛ حتماً public/realistic-assets را هم stage کنید.
SQL و env جدید نیاز نیست. تحلیل مجدد و هزینه API نیاز نیست؛ مدل ذخیره‌شده را دوباره باز کنید.
برای بررسی مبل واقعی حالت پیش‌فرض/Classic یا Luxury را انتخاب کنید؛ Modern و Minimal عمداً همان مدل متفاوت قبلی را دارند.

اعتبارسنجی:
475 تست و production build پاس شد.
بارگذاری GLTF و بافت واقعی در مرورگر، مسیر دسکتاپ و موبایل، ذخیره JPEG و ثابت بودن داده ورودی بررسی شد.
تطبیق ابعاد/ارتفاع/زمین، حرکت مدل واقعی همراه پیش‌نمایش، یک بار بارگذاری هر مدل و fallback در حالت خطا تست شد.
