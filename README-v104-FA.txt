پچ v104 — اصلاح مسیر PDF به BOQ

روی آخرین نسخه پروژه (v103) در ریشه ventra استخراج و فایل‌های هم‌نام را جایگزین کنید. پوشه src را داخل src نگذارید.

اصلاحات:
- صفحه‌ها به پلان طبقه، سازه، جدول بازشو، جدول مقدار، مشخصات، نما و جزئیات طبقه‌بندی می‌شوند.
- فقط پلان معماری با طبقه مشخص به جمع مساحت و شمارش پایه وارد می‌شود. نمایش دوباره یک طبقه دوباره جمع نمی‌شود.
- جدول‌ها به جای جمع با پلان، بر اساس نوع مقدار و محدوده فیزیکی تطبیق داده می‌شوند. داده متعارض کنار گذاشته و در گزارش ثبت می‌شود.
- تعداد پنجره هرگز جایگزین مترمربع پنجره نمی‌شود. تبدیل کیلوگرم میلگرد به تن بر اساس واحد است.
- مقدار مستند جدول برای ردیف‌های قابل تطبیق به BOQ منتقل می‌شود؛ ضرایب عمومی مساحت و مقدار یک‌عدد/یک‌تن برای PDF جایگزین سند نمی‌شوند.
- آیتم فاقد تطبیق روشن در کاتالوگ به حالت مقدار نامشخص/نیازمند بررسی می‌رود. درهای خاص یا بتن با گرید نامشخص خودکار به ردیف نامناسب نسبت داده نمی‌شوند.
- گسترش حدسی BOQ با AI برای این مسیر PDF غیرفعال است. تایید مهندس و کنترل نرخ همچنان لازم است.
- در تب Drawings، بخش گزارش تحلیل صفحات PDF و دکمه دانلود ventra-pdf-analysis-report.json اضافه شده است.
- نسخه‌های قدیمی تحلیل PDF باید دوباره تحلیل شوند؛ داده قبلی به صورت خودکار اصلاح نمی‌شود.

نصب/انتشار:
1) فایل‌ها را جایگزین کنید.
2) npm run build
3) اگر موفق بود، git add src/app src/lib src/services tests و سپس commit/push کنید.
4) منتظر Published شدن آخرین commit در Netlify بمانید.
5) PDF کامل آزمون را در یک پروژه جدید یا روی همان فایل دوباره Analyze کنید. سپس BOQ را دوباره Generate کنید؛ خروجی قبلی را معیار پچ جدید نگیرید.
6) گزارش PDF و خروجی BOQ جدید را برای کنترل ارسال کنید. نرخ‌های آزمایشی فقط برای مقایسه مبلغ لازم‌اند.

SQL یا env یا وابستگی جدید لازم نیست. فایل اصلی، APS و هندسه 3D با این پچ بازنویسی نمی‌شوند.

محدودیت صریح:
این پچ تضمین نمی‌کند AI همه صفحه‌ها، ابعاد و جدول‌ها را بی‌خطا بخواند. جدول ناقص/چندصفحه‌ای بدون محدوده کامل یا مشخصات مبهم نیازمند کنترل است. همه مقادیر سازه و همه 52 ردیف نمونه هنوز لزوماً به کاتالوگ قیمت کاربر تطبیق ندارند؛ موارد بدون تطبیق نباید با عدد ساختگی قیمت قطعی بگیرند.
PDF واقعی با API زنده در این محیط دوباره اجرا نشده است. تست‌های داده‌ای و کد موفق‌اند؛ پذیرش نهایی به گزارش و BOQ اجرای واقعی وابسته است.

اعتبارسنجی: 505 تست موفق؛ strict schema کنترل شد؛ ساخت worker نتلیفای موفق؛ بیلد تولید موفق.
