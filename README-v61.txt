Ventra v61 — ویرایش مدل سه‌بعدی عکس با پرامپت هوش مصنوعی

نصب
فایل‌های داخل ZIP را با همان مسیر روی ریشه پروژه کپی و جایگزین کنید.
سرور را متوقف کنید و npm run dev را دوباره اجرا کنید.
SQL جدید لازم نیست. کلید یا فایل محیطی در این ZIP نیست.
برای نتلیفای: تمام فایل‌ها، به‌ویژه route جدید را commit و push کنید؛ منتظر پایان Deploy بمانید.
OPENAI_API_KEY باید در محیط سرور محلی و محیط Netlify تنظیم باشد.
این مسیر همان احراز هویت و کنترل دسترسی/اشتراک قبلی پروژه را استفاده می‌کند.
اشتراک اپلیکیشن هزینه API OpenAI را حذف نمی‌کند.
مدل پیش‌فرض همان OPENAI_DESIGN_MODEL یا gpt-5.1 است.
OPENAI_SCENE_EDIT_MODEL فقط در صورت تمایل برای انتخاب مدل سازگار با خروجی ساختاریافته است؛ اجباری نیست.

چه تغییر کرد؟
پرامپت متنی JPG/PNG/WebP دیگر از چند regex ثابت اجرا نمی‌شود.
API /api/ai/scene-edit شرح کاربر و هندسه/وسایل فعلی را به OpenAI می‌دهد.
پاسخ به عملیات محدود افزودن، جابه‌جایی، حذف، چرخش، اندازه و رنگ وسیله، رنگ پالت و سبک تبدیل می‌شود.
عملیات در یک نسخه موقت اعمال و قبل از ذخیره بررسی می‌شود.
تداخل با اتاق، دیوار، وسایل، حفره و فضای محافظ درها رد می‌شود.
در صورت رد هندسه، یک بار فرصت اصلاح طرح به مدل داده می‌شود.
درخواست مبهم/پشتیبانی‌نشده، قطع API یا پاسخ ناقص باعث موفقیت جعلی نمی‌شود.
اگر نقشه حین درخواست عوض شود، پاسخ نقشه قبلی کنار گذاشته می‌شود.
دکمه بازگرداندن آخرین پرامپت اضافه شد؛ این تاریخچه فقط یک مرحله و در همان جلسه است.
ابعاد ساختمان، دیوارها، بازشوها و داده BOQ از این عملیات تغییر نمی‌کنند.
اشیای جدید پیشنهاد طراحی کاربرند و اندازه‌گیری از نقشه محسوب نمی‌شوند.

وسایل قابل اجرا
ماشین لباس‌شویی، یخچال، فریزر ایستاده، مبلمان، تخت، کمد، میز/صندلی ناهارخوری،
میز کار، میز جلو مبلی، کابینت، جزیره، تلویزیون، توالت، دوش، روشویی، وان،
اجاق، میز کنار تخت، فرش، گیاه عمومی آپارتمانی، گلدان گل عمومی، آینه، چراغ ایستاده، میز آرایش با آینه.
گیاه‌ها مدل عمومی هستند؛ نوع گیاه، برند یا جزئیات واقعی خاص تضمین نمی‌شود.
چراغ ایستاده هندسه و حباب روشن دارد؛ شبیه‌سازی نورپردازی فیزیکی واقعی نیست.
تغییر رنگ اجرا می‌شود؛ متریال سفارشی، مش سفارشی و رندر فوتورئال آزاد با این مسیر قابل اجرا نیست.
درخواست معماری/دوربین با عملیات این مسیر پشتیبانی نمی‌شود و باید پیام روشن بدهد.
این قابلیت مربوط به مدل مستقل عکس است؛ مسیر APS/DWG قبلی همچنان مستقل است.
