Ventra v89 — رفع قطع شدن درخواست تحلیل JPG روی Netlify

علت: تحلیل 3D طولانی در درخواست معمولی HTTP اجرا می‌شد و روی Netlify با 504 قطع می‌شد.
اصلاح: سایت درخواست را ثبت می‌کند؛ تابع preview-background تحلیل موجود را اجرا می‌کند؛ نتیجه در Supabase ذخیره می‌شود و مرورگر وضعیت را می‌پرسد. همان منطق هندسه، سهمیه، بررسی مالکیت پروژه و هزینه API حفظ شده است. روی localhost اجرای مستقیم باقی مانده است.

نصب — هر سه مرحله لازم است:
1) محتویات این پچ را در ریشه پروژه (کنار package.json) جایگزین کن. npm install را اجرا کن.
2) فایل supabase/migrations/20261012_preview_background_jobs.sql را در SQL Editor همان پروژه Supabase اجرا کن. این تنها SQL جدید این پچ است؛ نیاز نیست SQLهای قبلی دوباره اجرا شوند.
3) تمام فایل‌های پچ، به‌خصوص netlify.toml، scripts و netlify را commit و push کن. Netlify باید با فرمان زیر build کند:
node scripts/build-netlify-preview.mjs && npm run build
فرمان در netlify.toml قرار دارد. پس از استقرار، وجود تابع preview-background را در بخش Functions بررسی کن.

متغیرهای موجود OPENAI_API_KEY، NEXT_PUBLIC_SUPABASE_URL، NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY، SUPABASE_SERVICE_ROLE_KEY و متغیرهای حساب/Stripe باید در Netlify با scope شامل Functions تنظیم شده باشند. متغیر URL و SITE_ID را خود Netlify تأمین می‌کند. service role و OpenAI نباید NEXT_PUBLIC_ داشته باشند.

آزمایش:
در سایت آنلاین، همان JPG قبلی را از گوشی یا لپ‌تاپ تحلیل کن. برای پایان تحلیل منتظر بمان. درخواست آغاز باید 202 و پیگیری وضعیت در نهایت 200 یا خطای واقعی تحلیل بدهد؛ پاسخ 202 به معنی پایان تحلیل نیست. در قطع ارتباط، Retry در همان تب شناسه کار قبلی را پیگیری می‌کند و تحلیل را دوباره ارسال نمی‌کند.

حدود این اصلاح:
این پچ مخصوص مسیر /api/ai/design-3d-preview و گزارش 504 فرستاده‌شده است؛ مسیرهای مستقل DWG evidence و رندر تصویری به پس‌زمینه منتقل نشده‌اند. انتقال فایل، کیفیت هندسه و اعتبار OpenAI تضمین نمی‌شود. هزینه API و سهمیه Netlify همچنان برقرار است.
تست و بیلد محلی بررسی شده‌اند، اما استقرار روی حساب Netlify و اجرای OpenAI واقعی از این محیط انجام نشده؛ موفقیت آنلاین باید پس از نصب SQL و deploy بررسی شود.
جدول کارها خودکار پاکسازی زمانی ندارد؛ نتیجه‌ها با حذف پروژه/کاربر حذف می‌شوند. برای استفاده گسترده سیاست نگهداری نتیجه‌ها لازم است.
