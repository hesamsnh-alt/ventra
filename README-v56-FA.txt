پچ تجمعی v56 برای Ventra
فایل‌های زیپ را در ریشه پروژه کنار package.json جایگزین کنید.
سرور را متوقف کنید، npm run dev را اجرا کنید و صفحه را بازخوانی کنید.
برای اصلاحات ظاهری v56 نیازی به Analyze مجدد یا SQL جدید نیست.

تغییرات:
مدل در: دستگیره اهرمی در دو سمت با پایه گرد، لولا، قاب و جزئیات سطح، بافت چوب.
مکان، عرض، ارتفاع، جهت لولا و چرخش درها تغییر نکرده‌اند.
نمای داخلی پیش‌فرض: دیوارها نیمه‌شفاف می‌شوند تا داخل دیده شود.
دکمه «نمایش دیوارهای کامل» در کنترل دوربین برای بازگرداندن نمایش معمول.
این کنترل فقط مربوط به schematic تصویر است و هندسه گزارش/خروجی CAD را تغییر نمی‌دهد.
عنوان دکمه فارسی و عربی ترجمه شده است.

اعتبارسنجی: ۲۵۸ تست موفق، ESLint موفق، بیلد موفق.
تست هندسه با Three r71 انجام شده؛ رندر نهایی مرورگر هنوز مشاهده نشده است.
این پچ رندر فوتورئال ایجاد نمی‌کند و تأیید کامل مهندسی نیست.
