Ventra v97 — گیاهان و درختچه‌های آپارتمانی

شامل پچ‌های v89 تا v96 نیز هست. فایل‌ها با حفظ مسیر روی ریشه ventra جایگزین شوند. همه فایل‌های public/realistic-assets باید کپی و در GitHub stage شوند.

۷ گزینه جدید در پنل مبلمان:
1. گیاه برگ‌قلبی کوچک
2. گیاه برگ‌قلبی بزرگ
3. درختچه گلدانی متوسط
4. درختچه گلدانی بلند
5. کالاتیا متوسط
6. کالاتیا بزرگ
7. گیاه گوشتی رومیزی

این‌ها ۷ گزینه اندازه/مدل بر اساس ۴ خانواده مدل واقعی‌اند، نه ۷ گونه گیاهی متفاوت. گزینه قبلی گیاه آپارتمانی نیز حفظ شده است.

مسیر انتخاب:
3D > پنل مبلمان > کاتالوگ مبلمان > گیاهان و درختچه‌های آپارتمانی
مدل را انتخاب کن و روی کف بزن یا با ماوس روی کف بکش.
ابزارهای انتخاب، جابه‌جایی، چرخش در محور Z، تغییر اندازه، تعویض، حذف و برگشت موجود هستند.
نام‌ها فارسی، عربی و انگلیسی‌اند.
فقط رنگ گلدان در مدل واقعی گیاه تغییر می‌کند؛ رنگ طبیعی برگ‌ها با تغییر رنگ وسیله عوض نمی‌شود.
این اشیا تزئینی‌اند و دیوار، بازشو، هندسه پلان و BOQ را تغییر نمی‌دهند.

مدل‌های CC0 از Poly Haven داخل خود پروژه میزبانی می‌شوند؛ منابع در CREDITS.txt است.
سه مدل جدید فقط هنگام نیاز بارگذاری می‌شوند، با بافت 1K. یک بار بارگذاری هر مدل و استفاده مشترک هندسه/بافت برای نسخه‌های متعدد.
در صورت شکست دانلود از سایت، نمایش ساده قبلی باقی می‌ماند.

نصب در پوشه ventra:
npm install
npm run build

سپس commit و push همراه پوشه public/realistic-assets.
SQL، env جدید یا تحلیل مجدد لازم نیست.

اعتبارسنجی: 478 تست و production build پاس شد. هر ۷ گزینه در WebGL مرورگر، مسیر موبایل و دسکتاپ، و ذخیره JPEG بررسی شد. ابعاد، چرخش، تغییر اندازه، حذف، ثابت ماندن هندسه ساختمان و انتخاب تک‌مدل کالاتیا از بسته چندمدلی تست شد.
