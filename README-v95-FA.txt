Ventra v95 — اصلاح نور سفید و مه دیوارهای شفاف

شامل پچ‌های v89 تا v94 نیز هست؛ با حفظ مسیرها روی ریشه ventra جایگزین شود.

ایراد اصلاح‌شده:
در رندر قبلی، نور اصلی 3 و شدت محیط 0.8 بود که با متریال‌های روشن و چند دیوار شفاف روی هم، خروجی کم‌رنگ و سفید ایجاد می‌کرد.
اکنون نور اصلی 1.65، نور محیط 0.38، نور پرکننده 0.30 و exposure برابر 0.78 است.
opacity دیوارها فقط در حالت دیدن داخل از 0.18 به 0.045 کاهش یافته تا چند لایه سفید روی رنگ مبلمان جمع نشوند. با خاموش شدن حالت، شفافیت اصلی و سایه‌ها دقیقاً بازیابی می‌شوند؛ هندسه حذف یا جابه‌جا نمی‌شود.

این اصلاح نور و نمایش است. کیفیت V-Ray یا فوتورئال را تضمین نمی‌کند. محدودیت مدل‌ها و بافت‌های ساده هنوز وجود دارد. پچ‌های قبلی بیش از توان واقعی این مدل‌ها نمی‌توانند با تغییر نور به کیفیت عکس برسند.

نصب:
فایل‌ها جایگزین شوند، سپس در پوشه ventra:
npm install
npm run build

بعد از بیلد موفق commit/push و انتشار Netlify.
SQL، env جدید یا تحلیل دوباره لازم نیست؛ مدل ذخیره‌شده دوباره باز شود.

اعتبارسنجی:
469 تست و production build پاس شد.
مسیر WebGL دسکتاپ و موبایل، JPEG، عدم تغییر داده هندسه و پاک‌سازی منابع موقت بررسی شد.
تصویر صحنه آزمایشی پس از اصلاح بررسی شد؛ جای آزمون روی پروژه خود کاربر را نمی‌گیرد.
