VENTRA 3D CONSOLIDATED ARCHITECTURAL ENGINE — 2026-09-21

WHY
The previous sequence fixed isolated symptoms one at a time. This consolidated build
separates the problem into two stable responsibilities:

A) Geometry / semantics:
- AI reads rooms, labels, footprint, partitions, doors and windows
- local deterministic pixel-guide snapping ties near wall vertices to the real raster
- one global affine calibration is applied to the entire plan
- no post-hoc room dragging solver
- same source image is cached by SHA-256 for 24h so repeated Analyze clicks return
  the exact same scene instead of a new drifting interpretation
- furniture is deterministic and room-type based, not generated by the AI

B) Presentation:
- dark charcoal exterior walls
- warm off-white interior walls
- bedrooms = light oak
- living / dining / kitchen = light warm stone
- bathrooms = gray ceramic tile
- L-shaped sofa presentation
- improved bed textiles
- nightstands with lamps
- TV console, dining chairs, kitchen run, sink, stove, fridge
- rugs and simple plants
- softer studio-gray background and architectural lighting
- interactive orbit / pan / zoom remains unchanged

GENERALITY
No coordinates or room names from the 2-bedroom sample are hard-coded.
Rules are based on canonical room type and visible geometry, so the same engine is
used for other raster floor plans.

DWG / APS
No Autodesk/APS token, model loading, takeoff, BOQ, Supabase or Auth code is changed.
The viewer presentation changes apply only to Ventra's structured schematic scene.
APS remains authoritative for engineering geometry/quantities.
