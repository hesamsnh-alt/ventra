این زیپ پچ تجمعی v53 است، نه پروژهٔ کامل.

نصب:
۱. سرور npm run dev را با Ctrl+C متوقف کنید.
۲. زیپ را استخراج کنید؛ پوشه‌های src و tests را در پوشهٔ اصلی ventra کپی و فایل‌های هم‌نام را جایگزین کنید.
۳. npm run dev را اجرا کنید.
۴. پلان را دوباره Analyze کنید تا اصلاح ابعاد روی مدل ذخیره شود. رفرش تنها ابعاد مدل قبلی را تغییر نمی‌دهد.
SQL جدید، تغییر env یا نصب وابستگی اجرایی جدید لازم ندارد.

اصلاح ابعاد:
اندازه‌های چاپی سازگار اکنون شبکهٔ مشترک مختصات را تصحیح می‌کنند. اتاق‌ها، دیوارها، بازشوها و مبلمان همراه هم تنظیم می‌شوند؛ فضاها جداگانه جابه‌جا یا مستطیلی نمی‌شوند.
این اصلاح فقط تغییرهای کوچک و قابل دفاع در پلان‌های متعامد را اعمال می‌کند. برچسب‌های متناقض، تغییرهای بزرگ یا هندسهٔ مورب به‌زور اصلاح نمی‌شوند و علت عدم اعمال در گزارش می‌آید.
مرور دوم مبلمان نیز همان تبدیل را به کار می‌برد تا وسایل با دیوارهای اصلاح‌شده ناهماهنگ نشوند.
گزارش هندسه اکنون اندازهٔ چاپی، اندازهٔ مدل و اختلاف آن‌ها را برای هر اتاق نشان می‌دهد.
نسخهٔ تحلیل باید source-dimension-material-v54-20261010 باشد.

ظاهر:
کف اتاق‌ها بافت چوب یا سرامیک با مقیاس متری و ناهمواری ظریف دارد؛ متریال نور و براقیت را دریافت می‌کند.
مختصات بافت برای مثلث‌های کف تنظیم شده است تا الگو روی هر مثلث کشیده نشود.
پتو به‌جای یک مکعب تخت، سطح پارچهٔ چین‌دار داخل ابعاد همان تخت دارد؛ وسیلهٔ جدیدی به پلان اضافه نمی‌شود.
بافت‌ها محلی و بدون دانلود یا درخواست API تولید می‌شوند.
این نسخه رندر فوتورئال یا هم‌کیفیت با تصویر تولیدی ChatGPT تأییدشده نیست.
