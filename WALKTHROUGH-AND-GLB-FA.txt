Ventra v141 — گشت داخلی و ورود مستقیم مدل GLB

این بسته شامل تغییرات v140 و v141 روی آخرین ZIP کامل ارسالی خودت است؛ نیازی نیست v140 را جداگانه نصب کنی.
بسته شامل فایل‌های تغییرکرده است، نه کل پروژه.

نصب:
1. سرور لوکال را با Ctrl+C متوقف کن و از پروژه فعلی بکاپ بگیر.
2. پوشه src داخل این بسته را با E:\ventra\src ادغام کن و فایل‌های همنام را جایگزین کن. پوشه src اصلی را حذف نکن.
3. پوشه tests را نیز در tests پروژه ادغام کن. وابستگی و package.json عوض نشده است.
4. در PowerShell اجرا کن:
cd E:\ventra
npm run build
npm run dev
5. برای نسخه آنلاین، این srcهای جدید و تغییرکرده را به GitHub اضافه کن و deploy نتلیفای را اجرا کن. فایل .env.local را commit نکن.

گشت داخلی:
یک مدل JPG/Image یا DWG Interior را باز کن؛ بالای ستون ابزارهای کنار مدل، «گشت داخل پروژه» قرار دارد.
با کلیک وارد مدل همان طبقه می‌شوی. ارتفاع چشم 1.60 متر، سرعت حرکت 1.2 متر بر ثانیه است.
کیبورد: W/S جلو و عقب؛ A/D حرکت جانبی. جهت بالا/پایین جلو و عقب؛ جهت چپ/راست چرخش.
با کشیدن روی تصویر اطراف را ببین. موبایل: کشیدن تصویر برای نگاه و نگه‌داشتن دکمه‌های جهت برای حرکت.
Esc یا «خروج از گشت» نمای دوربین قبلی را برمی‌گرداند. تغییر دوربین، source یا بستن مدل گشت را متوقف می‌کند.
تغییر تب مرورگر یا از دست رفتن فوکوس، حرکت نگه‌داشته‌شده را قطع می‌کند.
هنگام گشت، ویرایش مبلمان و متریال غیرفعال است؛ پس از خروج دوباره فعال می‌شوند.
دیوارها در گشت مات می‌شوند و بعد از خروج وضعیت شفافیت قبلی برمی‌گردد.
برخورد: محدوده کف، حفره‌های ثبت‌شده، دیوارها و حجم مبلمان. عبور فقط از بازشوهای در با عرض و ارتفاع کافی انجام می‌شود؛ پنجره مسیر عبور نیست.
اگر مرز کف/دیوارها معتبر نباشند یا فضای خالی پیدا نشود، ورود با پیام متوقف می‌شود.
این گشت فقط همان طبقه است؛ پله، تعویض ارتفاع بین طبقات و ورود با هدست VR در این نسخه پیاده نشده‌اند.
هندسه استخراج‌شده ممکن است خطا داشته باشد؛ این نمایش تأیید اندازه‌ها و ایمنی واقعی ساختمان نیست.

مدل آماده از اسکن آیفون:
پنل مبلمان ← کتابخانه مدل ← «آپلود مدل آماده GLB · بدون هزینه تولید».
مدل را از اپ اسکن به صورت GLB ایستا با بافت داخلی و بدون Draco/KTX خروجی بگیر؛ PNG، عکس پانوراما، PLY و Gaussian Splat مدل قابل ورود به این مسیر نیستند.
حداکثر فایل 25MB، حداکثر 16 بافت، هر بافت حداکثر 4096 پیکسل و مجموع بافت‌ها حداکثر 64MP.
فرمت USDZ باید ابتدا در نرم‌افزار مناسب به GLB تبدیل شود؛ تبدیل USDZ در این نسخه وجود ندارد.
فایل مستقیماً در فضای خصوصی آپلود می‌شود تا از محدودیت حجم بدنه درخواست نتلیفای عبور نکند. سرور پیش از افزودن به کتابخانه آن را دوباره بررسی می‌کند.
پس از آپلود، مدل را انتخاب کن، ابعاد واقعی را بر حسب متر و نوع وسیله را تنظیم کن و جای‌گذاری را بزن؛ بعد روی کف کلیک کن.
ابعاد اولیه متناسب با شکل فایل ولی پیشنهادی‌اند؛ اندازه اسکن را دستی تأیید کن.
برای آپلود GLB، گشت و متریال هیچ اعتبار Meshy یا OpenAI مصرف نمی‌شود. ذخیره و ترافیک فایل تابع سهمیه Supabase است.
اگر آپلود قطع شد، دوباره انتخاب فایل لازم است؛ اگر بارگذاری تمام و ثبت نهایی قطع شود، ممکن است فایل خصوصی بدون ردیف کتابخانه باقی بماند و به پاک‌سازی مدیر نیاز داشته باشد.

تولید از عکس نیز از v140 حفظ شده؛ برای آن تنظیم Meshy لازم است. راهنمای PHOTO-MODEL-SETUP-FA.txt مربوط به تنظیم آن مسیر است.
فقط برای مدل اسکن‌شده/آماده، خرید Meshy لازم نیست.

دیتابیس:
همان سه جدول و bucket خصوصی v140 استفاده می‌شود که در Supabase متصل ساخته و بررسی شده‌اند؛ v141 تغییر schema تازه ندارد.
برای یک Supabase دیگر، database/personal-assets.sql را اجرا کن. تنظیمات قبلی Auth، BOQ و project-files تغییر نکرده‌اند.

بررسی:
113 تست خودکار کد، برخورد، ورود مدل، مالکیت و رگرسیون کنترل‌ها موفق شدند.
build تولیدی Next.js موفق؛ دو تست مرورگر واقعی برای آپلود/انتخاب فایل و شروع/حرکت/خروج گشت موفق.
تست‌ها از پاسخ‌های شبیه‌سازی‌شده سرویس استفاده می‌کنند؛ درخواست پولی اجرا نشده است.
رندر GPU، هدست VR، فایل اسکن واقعی آیفون و انتقال آنلاین Supabase Storage از سمت مرورگر کاربر هنوز آزمایش نشده‌اند.
یک ایراد v140 هم اصلاح شد: نمایشگر اصلی اکنون قابلیت بارگذاری GLB شخصی را به پنل مبلمان اعلام می‌کند.

بازگشت:

برای بازگشت به v140 از بکاپ پروژه فعلی‌ات استفاده کن؛ rollback این بسته مبنای ZIP اصلی است.
