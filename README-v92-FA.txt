Ventra v92 — بهبود نمایش واقعی‌تر مدل سه‌بعدی

تغییرات این نسخه مخصوص ظاهر رندر است:
- لبه‌های چندمیلی‌متری نرم روی اجزای مبلمان و کابینت‌ها، با حفظ ابعاد و محل آن‌ها.
- بافت ریزتر پارچه و چوب، برجستگی بسیار کم سطح، و بازتاب متفاوت فلز و سطوح مات.
- نور اصلی گرم‌تر و نور مکمل متعادل‌تر؛ تنظیم gamma سازگار با موتور قدیمی APS حفظ شده است.
- سایه نرم تماس زیر مبلمان زمینی؛ این سایه‌ها قابل انتخاب نیستند و وارد BOQ یا داده هندسی نمی‌شوند.
- گیاه پیش‌فرض برگ‌دار شده و از فرم توپ‌های ساده خارج شده است.
- رفع اعمال نشدن متریال light_oak روی کف نشیمن: اکنون پیش‌فرض پارکت واقعاً در رندر نشان داده می‌شود.

دیوارها، بازشوها، جای اتاق‌ها و هندسه ورودی تغییر نکرده‌اند. کنترل‌های چرخش/جابجایی/اندازه مبلمان باقی مانده‌اند. ظاهر داخلی بازسازی‌شده JPG و DWG که از همین renderer استفاده می‌کند این تغییرات را می‌گیرد؛ متریال مدل اصلی Autodesk/APS دستکاری نشده است.

نصب:
فایل‌های پچ را در ریشه پروژه کنار package.json جایگزین کن. بسته شامل اصلاحات v89 تا v91 هم هست؛ npm install بزن و تغییرات را commit و push کن. منتظر Deploy موفق Netlify بمان و سپس سایت را با Ctrl+Shift+R تازه کن. SQL و متغیر محیطی جدید لازم نیست.
برای دیدن تغییرات ظاهری، تحلیل پولی پلان را دوباره اجرا نکن؛ همان مدل ذخیره‌شده را در تب 3D باز کن. تصویر دانلودشده قبلی تغییر نمی‌کند؛ Save JPG جدید بگیر.

اعتبارسنجی:
464 تست و production build موفق بودند. قبل/بعد یک صحنه نمونه با رندر واقعی WebGL و Three.js r71 در مرورگر دسکتاپ بررسی شد. ابعاد مبلمان، انتخاب‌پذیری، source data و دوربین در تست‌ها بررسی شدند. تست مستقیم روی آیفون یا پروژه آنلاین شما انجام نشده است.

حد این مرحله:
این بهبود برای مدل سه‌بعدی تعاملی است؛ فوتورئالیسم در حد V-Ray یا تصویر تولیدی ChatGPT نیست. هنوز مدل‌های مبلمان عمدتاً procedural هستند و نورپردازی global illumination یا path tracing ندارند. دستیابی به آن سطح نیاز به مدل‌های سه‌بعدی باکیفیت‌تر و موتور رندر پیشرفته‌تر دارد. این پچ خطای تشخیص هندسه پلان را اصلاح نمی‌کند.
