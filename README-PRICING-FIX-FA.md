# اصلاح Pricing برای اشتراک موجود
این ZIP کامل، ادامه نسخه Navigation/Billing است. محتوای آن را داخل پوشه ventra جایگزین کنید و .env.local خود را حفظ کنید.
صفحه Pricing ابتدا وضعیت اشتراک را از API حساب واردشده می‌خواند. اشتراک موجود (حتی past_due/incomplete) دکمه مدیریت اشتراک دارد و Checkout جدید نمی‌سازد. وضعیت canceled/incomplete_expired می‌تواند دوباره Checkout باز کند؛ trial دوباره تضمین نمی‌شود.
پاسخ 409 با کد SUBSCRIPTION_EXISTS به Billing هدایت می‌شود و خطای کنسول ایجاد نمی‌کند. دیگر پاسخ‌های 409 مانند چند پروفایل مبهم، خطا باقی می‌مانند و پنهان نمی‌شوند. اگر وضعیت Billing خوانده نشود دکمه خرید غیرفعال است و لینک Billing قابل استفاده است.
۹ تست مرتبط موفق و lint فایل‌های اصلاح‌شده بدون خطا؛ build با Next موجود محیط 16.2.10 انجام شده. package/lock نسخه 16.3.8 ورودی حفظ شده است. پرداخت زنده انجام نشده؛ تنظیمات Stripe نسخه قبلی همچنان لازم است. هندسه سه‌بعدی تغییر نکرده است.
