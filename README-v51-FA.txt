پچ v51 شامل اصلاحات v50 و رفع شروع Viewer در پنل صفراندازه است.
از فایل‌های متناظر بکاپ بگیرید، محتویات را داخل پوشه اصلی ventra جایگزین کنید، .env.local را نگه دارید. SQL جدید و تحلیل مجدد لازم نیست. Ctrl+C، سپس npm run dev و Ctrl+Shift+R.
راه‌اندازی پنل مخفی تا نمایان‌شدن آن منتظر می‌ماند؛ انتظار هنگام بسته‌شدن کامپوننت لغو می‌شود. خطای راه‌اندازی Viewer متعلق به همان اجرا را پاک می‌کند. صحت هندسه پلان و کیفیت فوتورئال با این اصلاح تأیید نمی‌شود.
