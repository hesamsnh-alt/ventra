Ventra v88 — مرتب‌سازی محیط پروژه

این بسته شامل اصلاحات نسخه‌های 85 تا 88 است. فایل‌ها را در ریشه پروژه جایگزین کنید؛ پوشه src باید در کنار package.json قرار بگیرد، نه داخل src دیگری.

نسخه 88 فقط ارائه و چیدمان را تغییر می‌دهد: رنگ و فاصله‌ها یکدست‌تر، پنل‌ها جمع‌وجورتر، تنظیمات برآورد، خروجی BOQ، جزئیات اسناد، دعوت اعضا و تنظیمات قرارداد بازشونده شده‌اند. فعالیت‌های زمان‌بندی هم جداگانه باز می‌شوند. متن عنوان‌های جدید فارسی و عربی دارد.
هیچ دکمه، گزینه، داده یا قابلیت قبلی حذف نشده است. کنترل‌های داخل بخش‌های بسته همچنان در React باقی می‌مانند. رویدادها و مقدارهای فرم‌های تغییرکرده با نسخه قبل مقایسه شدند.
نمایشگرهای APS و 3D داخل بخش بازشونده جدید قرار نگرفته‌اند. برای نسخه 88 تغییر SQL یا متغیر محیطی لازم نیست.

پس از نصب npm run build را اجرا کنید و تغییرات را commit و push کنید. سپس منتظر استقرار موفق Netlify بمانید.
بررسی عملی روی حساب واقعی و آیفون شما انجام نشده؛ پس از استقرار، 3D، خروجی PDF و فرم‌ها را روی موبایل هم بررسی کنید.
