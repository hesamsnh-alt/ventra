Ventra GLB furniture library
============================

This folder is reserved for future upgraded 3D furniture assets.

Recommended filenames:
- sofa.glb
- armchair.glb
- bed.glb
- dining_table.glb
- chair.glb
- wardrobe.glb
- tv_unit.glb
- kitchen_counter.glb
- kitchen_island.glb
- nightstand.glb

Important:
The current V12 patch improves the furniture procedurally and fixes the floors and doors.
True runtime GLB loading should be done only after migrating the standalone schematic renderer
from Autodesk's embedded legacy THREE runtime to a modern standalone three.js runtime.
