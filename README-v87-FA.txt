Ventra v87 — نمایش و خروجی سه‌زبانه BOQ، همراه v85 و v86
فایل‌های src و tests را در ریشه ventra جایگزین کنید و سرور را با Ctrl+C و npm run dev دوباره اجرا کنید.
این بسته اصلاحات v85 و v86 را هم دارد؛ نصب جداگانه آن‌ها لازم نیست. SQL جدید لازم نیست.
در BOQ زبان فارسی یا عربی را انتخاب کنید؛ بخش‌ها و شرح‌های شناخته‌شده ترجمه می‌شوند.
برای شرح‌های اختصاصی، روی «ترجمه شرح‌های باقی‌مانده BOQ» بزنید.
این دکمه API هوش مصنوعی را فراخوانی و سهمیه تحلیل BOQ را مصرف می‌کند. هر درخواست حداکثر ۱۵۰ متن را ترجمه می‌کند؛ برای متن‌های بیشتر دوباره دکمه را بزنید.
شرح‌ها برای ترجمه به سرویس OpenAI ارسال می‌شوند؛ قیمت و مقدار ردیف‌ها در درخواست ترجمه ارسال نمی‌شود، مگر عددی جزو خود شرح عملیات باشد.
متن اصلی BOQ، مقدار، نرخ، مبالغ و جمع‌ها با تغییر زبان بازنویسی نمی‌شوند.
ویرایشگر شرح همچنان متن اصلی را نشان می‌دهد و ویرایش آن تغییر واقعی داده پروژه است.
CSV و Excel شرح، عنوان ستون‌ها و جمع‌بندی را با زبان انتخاب‌شده می‌دهند؛ PDF از چاپ همین صفحه استفاده می‌کند.
ترجمه‌های اختصاصی فقط در نشست همین مرورگر نگهداری می‌شوند؛ روی دستگاه دیگر ممکن است نیاز به ترجمه مجدد باشد.
اگر کلید/اعتبار OpenAI یا سهمیه پروژه کافی نباشد، شرح اصلی نمایش داده می‌شود و ترجمه اختصاصی ناموفق خواهد بود.
تغییر مشخصات عددی یا کد مصالح در پاسخ ترجمه رد می‌شود؛ معنی فنی ترجمه همچنان باید توسط مهندس بررسی شود.
اعتبارسنجی: ۴۴۵ تست پاس شدند؛ بیلد و بررسی ترجمه‌ها موفق بودند. فراخوانی زنده OpenAI با حساب کاربر در این محیط اجرا نشده است.
