Ventra v73 — DWG drawing regions and furnished reconstruction

نصب:
این پچ را در ریشه پروژه ونترا استخراج کنید؛ پوشه src آن با src پروژه ادغام شود.
پوشه src را داخل src دیگری کپی نکنید. فایل .env.local تغییر نمی‌کند.
این پچ SQL جدید ندارد. اصلاحات قبلی v70 تا v72 جداگانه باقی می‌مانند.
بعد از نصب: npm test و npm run build. سپس فایل‌های تغییرکرده را commit و push کنید.
روی نتلیفای منتظر موفق شدن deploy جدید بمانید.

استفاده:
1. Drawings: همان فایل DWG را انتخاب و استخراج هندسه را تکمیل کنید.
2. مقیاس باید از واحد/ابعاد تأییدشده نقشه موجود باشد. اخطار DWG scale is not available
   یعنی داده کافی برای بازسازی متریک ندارید؛ این پچ واحد را حدس نمی‌زند.
3. 3D Model > Reconstruct 3D. پنل «طبقات DWG و مبلمان» ظاهر می‌شود.
4. محدودهٔ نقشه: هر محدوده را جدا انتخاب کنید؛ در حالت جدا، کف آن در z=0 نمایش داده می‌شود.
   شمارهٔ محدوده ترتیب واقعی طبقات نیست. نقشه‌های کنار هم می‌توانند نما یا گزینه جایگزین باشند.
   حالت همه، محدوده‌ها را برای مرور روی هم نمایش می‌دهد، نه به‌عنوان تأیید طبقات ساختمان.
5. تعیین نوع اتاق‌ها: اگر استخراج نامی مانند Room 1 داده، استفادهٔ واقعی آن را انتخاب کنید.
   اسم اصلی نقشه تغییر نمی‌کند. نام‌های فارسی، عربی و انگلیسی شناخته‌شده هم استفاده می‌شوند.
6. «چیدمان و ذخیرهٔ مبلمان» را بزنید. برای WC: توالت، دوش و روشویی؛ خواب: تخت و میز آرایش؛
   نشیمن: سوفا، تلویزیون و گیاه؛ آشپزخانه: تجهیزات و میز و صندلی در فضای امن پیشنهاد می‌شود.
7. انتخاب نوع اتاق‌ها همراه هندسه در پروژه ذخیره می‌شود و از مسیر cloud قبلی همگام می‌شود.
   خطای cloud جدا نمایش داده می‌شود؛ برای همگام‌سازی موفق، سرویس سرور و مجوز نوشتن لازم است.
   در بازسازی بعدی، چیدمان ذخیره‌شده دوباره ساخته می‌شود. انتخاب محدودهٔ نمایشی موقت است.

محدودیت‌های روشن:
- فقط دیوارهای استخراج‌شدهٔ معتبر بازسازی می‌شوند. تشخیص اتاق به roomPolygons نیاز دارد.
- اگر مرز اتاق استخراج نشده، مبلمان روی فضای خیالی ساخته نمی‌شود؛ ابتدا استخراج/بررسی مرز لازم است.
- وسیله‌ای که با دیوار، در یا مبلمان تداخل کند اضافه نمی‌شود و تعداد موارد بدون فضای امن گزارش می‌شود.
- DWG با طبقات روی هم در یک XY یا لایه‌های مبهم: تشخیص خودکار طبقه از فاصله XY کافی نیست؛
  viewهای جدا را انتخاب کنید. این نسخه ابزار رسم دستی مرز طبقه یا استخراج اختصاصی layer ندارد.
- انتخاب هر محدوده هندسهٔ همان محدوده را نشان می‌دهد؛ پلان طبقه اول برای دیگر طبقات تکثیر نمی‌شود.
- مدل اصلی Autodesk، اندازه‌گیری‌ها، BOQ و Estimate با مبلمان پیشنهادی تغییر نمی‌کنند.
- بازسازی و مدل مبلمان را می‌توان با ابزارهای دوربین و Save JPG موجود مشاهده و ذخیره کرد.
- کنترل drag/rotate/size پنل قبلی مخصوص مدل schematic/JPG است؛ این پچ ویرایش تعاملی مبلمان DWG اضافه نمی‌کند.
- فایل DWG اصلی و نمایش زنده روی گوشی شما در این محیط آزمایش نشده؛ کیفیت نتیجه همان پروژه باید بررسی شود.
