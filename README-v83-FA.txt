Ventra v83 — ترجمه زمان‌بندی فارسی و عربی
این پچ برای پروژه فعلی Ventra است و فقط بخش نمایش زمان‌بندی را اصلاح می‌کند.
محتویات src و tests را در ریشه پروژه ventra کپی و فایل‌های هم‌نام را جایگزین کنید.
سپس سرور محلی را با Ctrl+C متوقف و npm run dev را اجرا کنید.
برای سایت، فایل‌ها را commit/push و انتشار موفق Netlify را بررسی کنید.
در پروژه > Schedule زبان را فارسی یا عربی انتخاب کنید؛ BOQ پروژه را بارگذاری کنید.
رشته‌ها، روش‌ها، توضیحات، ظرفیت تولید، اولویت‌ها، وضعیت‌ها و خطاهای برنامه ترجمه شده‌اند.
متن اصلی ردیف‌های BOQ و توضیحات واردشده توسط کاربر حفظ می‌شوند.
تاریخ‌ها همچنان میلادی و محاسبه روز جاری همچنان بر اساس زمان دبی است؛ تقویم شمسی اضافه نشده.
نرخ‌ها و روش‌های موجود با این پچ به استاندارد ایران تبدیل نمی‌شوند.
این پچ موتور برنامه‌ریزی هوشمند جدید یا SQL جدید ندارد.
اعتبارسنجی: ۱۹ تست زمان‌بندی/ترجمه پاس شدند، بررسی ترجمه‌ها و بیلد موفق بود.
