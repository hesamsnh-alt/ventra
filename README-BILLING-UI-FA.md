Billing به دو کارت وضعیت اشتراک و مدیریت کارت/فاکتورها تغییر کرد. دکمه Manage card & invoices زرد و واضح است و همان API موجود Stripe Portal را فراخوانی می‌کند. حالت انتظار، غیرفعال‌سازی هنگام درخواست، پیام خطا و Refresh status اضافه شد. تاریخ آزمایشی تنها برای وضعیت trialing نمایش داده می‌شود؛ تاریخ قدیمی روی اشتراک active دیگر نمایش داده نمی‌شود. نمایش موبایل تک‌ستونی است. build و lint فایل اصلاح‌شده و ۱۲ تست منطق Billing موفق؛ ظاهر در مرورگر تعاملی و پرداخت زنده بررسی نشده است. این ZIP کامل شامل اصلاحات قبلی است. محتوایش را داخل ventra جایگزین کنید و .env.local خود را حفظ کنید.
