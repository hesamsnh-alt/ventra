Ventra v93 — ارتقای رندر فیزیکی سه‌بعدی

این پچ شامل تغییرات v89 تا v92 و ارتقای جدید است. فایل‌ها را با حفظ مسیرها روی پوشه اصلی پروژه جایگزین کنید؛ پوشه src را داخل src نگذارید.

تغییرات:
- نمای داخلی بازسازی‌شده JPG و DWG از رندر جدید Three.js با متریال PBR استفاده می‌کند.
- نور محیطی استودیویی داخلی، انعکاس متناسب با زبری متریال، سایه و tone mapping فیلمی.
- سایه تماس SSAO در حالت دسکتاپ. موبایل برای مصرف کمتر حافظه از مسیر تک‌مرحله‌ای بدون SSAO استفاده می‌کند.
- اگر ساخت رندر جدید به دلیل نبود WebGL2 ممکن نباشد، مسیر قبلی امتحان می‌شود.
- نمای اصلی Autodesk تغییر نمی‌کند؛ ارتقا متعلق به نمای داخلی بازسازی‌شده است.
- هندسه، مختصات، بازشوها، انتخاب و ابزارهای مبلمان بر مدل اصلی باقی می‌مانند. رندر فقط یک کپی نمایشی می‌سازد.
- پاک‌سازی منابع رندر و اشیای موقت هنگام ویرایش و بستن نمای سه‌بعدی.

این یک رندر بلادرنگ PBR است، نه V-Ray و نه path tracing. مدل‌های ساده مبلمان همچنان ساده‌اند؛ برای رسیدن به واقع‌گرایی کامل، مدل‌های مبلمان با جزئیات بالاتر و رندر آفلاین نیز لازم است. تصویر تبلیغاتی یا مدل جایگزین ساختگی تولید نشده است.

نصب در PowerShell داخل پوشه ventra:
npm install
npm run build

پس از موفق شدن build، فایل‌های تغییرکرده را commit و push کنید تا Netlify نسخه جدید را deploy کند.
اگر SQL مربوط به v89 را قبلاً اجرا کرده‌اید، SQL یا متغیر محیطی جدید لازم نیست.
برای مشاهده کیفیت جدید، مدل ذخیره‌شده را دوباره در تب 3D باز کنید. نیاز به تحلیل دوباره و هزینه API نیست.

اعتبارسنجی:
466 تست پاس شد؛ production build موفق بود.
بررسی WebGL در مرورگر برای مسیر دسکتاپ و موبایل: خروجی غیرخالی، خروجی JPEG، ثابت بودن داده هندسی، و آزاد شدن هندسه پیش‌نمایش موقت.
این تست مرورگر جای تست روی تمام مدل‌های گوشی واقعی را نمی‌گیرد.
