این بسته شامل اصلاح محدود فهم پلان و دو اصلاح نمایشگر قبلی است.
سه فایل را با همان مسیر در ریشه پروژه جایگزین کنید. سرور را متوقف و npm run dev اجرا کنید و Ctrl+Shift+R بزنید.
نقشه قبلی ذخیره‌شده خودکار عوض نمی‌شود؛ همان تصویر اصلی را دوباره Analyze کنید. SQL تغییر ندارد.
تحلیل تصویر اکنون reasoning=medium دارد؛ زمان و هزینه درخواست ممکن است افزایش یابد. OPENAI_3D_PREVIEW_REASONING اختیاری است و low/medium/high را قبول می‌کند.
دستور تحلیل بر فهم کلی فضا، نوشته‌های چندزبانه و تفکیک خطوط مبلمان/اندازه/دیوار تمرکز دارد. اعتبارسنجی هندسه حذف نشده است.
این بسته رندر فوتورئال تولید نمی‌کند و خروجی دقیقاً معادل ChatGPT تضمین نشده است. درخواست واقعی OpenAI روی این پلان اینجا اجرا نشده است.
