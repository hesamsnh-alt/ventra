متغیر قبلی .env.local را نگه دارید:
VENTRA_FREE_USER_ID=be9cd2a5-0c45-489c-a37f-e03a4511790d
Ctrl+C سپس npm run dev. هیچ SQL جدیدی لازم نیست.
حساب مالک از مصرف سهمیه دیتابیس معاف است؛ درخواست‌های او دیگر در جدول مصرف ثبت نمی‌شوند. کنترل ورود و مالکیت پروژه و جمع‌کردن درخواست‌های همزمان در یک پردازش حفظ شده است. تاریخچه قدیمی حذف نشده. مشتری‌های دیگر سهمیه و اشتراک قبلی را دارند. هزینه API همچنان واقعی است.
