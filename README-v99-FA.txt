پچ v99 — ابزارهای کنار مدل سه‌بعدی

این پچ را روی نسخه v98 نصب کنید. محتوای ZIP را در ریشه پروژه ventra استخراج و فایل‌های هم‌نام را جایگزین کنید؛ پوشه src را داخل src قرار ندهید.
نیازی به دانلود دوباره مدل‌ها و گیاهان، تغییر SQL، متغیرهای محیطی یا نصب وابستگی جدید نیست.

تغییرات:
- ابزار دوربین و دکمه شفاف/توپر شدن دیوارها کنار خود مدل.
- انتخاب چند وسیله با دکمه انتخاب چندتایی یا Shift/Ctrl و کلیک.
- کپی مبلمان انتخاب‌شده: Copy یا Ctrl/Cmd+C، سپس کلیک روی کف برای جای‌گذاری؛ Ctrl/Cmd+V برای جای‌گذاری دوباره.
- حذف گروه انتخاب‌شده با دکمه حذف یا کلید Delete. هنگام تایپ در فیلدها حذف اجرا نمی‌شود.
- نمایش کادر انتخاب؛ کادرها در عکس دانلودی وارد نمی‌شوند.
- جای‌گذاری نامعتبر کل گروه را رد می‌کند و مدل قبلی حفظ می‌شود. معماری اصلی تغییر نمی‌کند.

پس از جایگزینی: npm run build
اگر بیلد موفق بود، تغییرات را commit و push کنید و منتظر انتشار Netlify بمانید.
نیازی به تحلیل دوباره نقشه نیست.

اعتبارسنجی: 485 تست موفق، بیلد تولید موفق، آزمایش مرورگر دسکتاپ و موبایل برای انتخاب چندتایی، کپی، حذف، دوربین و شفافیت دیوارها.
