VENTRA v42 — wait for calibrated DWG geometry before automatic reconstruction

رفع regression اضافه‌شده در v41: شروع بازسازی از boot صرفاً با پایان translation کافی نبود و خطای CALIBRATION MISSING می‌داد.

نصب: سرور Ctrl+C، پوشه‌های پچ را در ریشه پروژه کامل ventra کپی و جایگزین کنید، npm run dev -- --webpack، سپس Ctrl+Shift+R مرورگر. .env.local و dependencies تغییر نکرده‌اند.
این بسته تجمعی اصلاحات v39، v40 و v41 نسبت به ventra 1.zip را هم دارد.

رفتار v42:
- پایان translation فقط نمایش شیت/مدل Autodesk را آماده می‌کند.
- بازسازی DWG دوبعدی منتظر مقیاس معتبر، خطوط دیوار تأییدشده و URN همان فایل می‌ماند.
- resolver بازسازی و بررسی آمادگی مشترک‌اند؛ مقیاس از factor ذخیره‌شده، واحد صریح یا نسبت‌های اندازه‌گیری موجود گرفته می‌شود، نه فرض متر/میلی‌متر.
- بعد از ذخیره هندسه در Drawing Center، رویداد همان تب به 3D می‌رسد؛ نمایشگر بدون راه‌اندازی دوباره Autodesk، takeoff تازه را بررسی می‌کند.
- هر مجموعه هندسه آماده، یک بار خودکار امتحان می‌شود؛ خطاها loop بازسازی ایجاد نمی‌کنند.
- دکمه دستی Reconstruct 3D هم ابتدا آمادگی را بررسی می‌کند و بدون مقیاس، پیام راهنما می‌دهد.
- اگر مقیاس/هندسه واقعاً موجود نیست، مدل حدسی ساخته نمی‌شود. باید استخراج/کالیبراسیون DWG در Drawings تکمیل شود؛ این پچ داده‌ای را که منبع فراهم نکرده تولید نمی‌کند.

تست: DWG را تحلیل کنید، منتظر Advanced architectural ... takeoff completed بمانید، سپس 3D را باز کنید. در انتظار استخراج نباید Console Error کالـیبراسیون ظاهر شود. بعد از آماده‌شدن داده، بازسازی شروع می‌شود. اگر پیام DWG scale is not available yet باقی ماند، اطلاعات مقیاس واقعاً به takeoff نرسیده است؛ متن پیام و لاگ extraction را ارسال کنید.

اعتبارسنجی: 17 آزمون مقیاس، تطبیق منبع، داده در انتظار، ورودی ماوس، سبک و رندر مش موفق. Production build با Next 16.2.10 و webpack موفق؛ package.json شما تغییر ندارد. مرورگر و حساب زنده APS شما اینجا آزمایش نشده‌اند.
