Ventra v71 — اصلاح تشخیص مالکیت مسیر APS
این پچ را پس از v70 روی همان پروژه نصب کنید.

علت خطای گزارش‌شده:
APS جداکننده‌های مسیر شیء را به صورت %2F برمی‌گرداند. کد v70 فقط / را تشخیص می‌داد و مدل دارای مالک/پروژه را اشتباهاً قدیمی حساب می‌کرد. این رگرسیون در v71 اصلاح شده است.

اصلاح:
فقط مسیر شیء یک بار برای تشخیص مالک و پروژه decode می‌شود. شناسهٔ کامل اصلی برای توکن OAuth بدون تغییر حفظ می‌شود. بررسی مالکیت، عضویت پروژه و محدودکردن توکن به همان مدل همچنان برقرار است. مسیرهای با encoding خراب یا کاراکتر کنترلی رد می‌شوند.

نصب محلی:
۱. سرور npm run dev را با Ctrl+C متوقف کنید.
۲. پوشه‌های src و tests این پچ را در ریشهٔ پروژهٔ فعلی کپی و فایل‌های هم‌نام را جایگزین کنید.
۳. npm run dev را اجرا و صفحه را تازه‌سازی کنید.
برای همین خطای %2F نیازی به آپلود مجدد DWG یا تنظیم نگاشت مدل قدیمی ندارید.
SQL جدید، کلید جدید یا شارژ API برای رفع همین خطای 403 لازم نیست.

برای سایت Netlify:
فایل‌ها را commit و push کنید و پس از Deploy موفق دوباره بررسی کنید.

اعتبارسنجی:
335 تست خودکار پاس شده‌اند. تست مسیرهای %2F و %2f، حفاظت در برابر دسترسی کاربر غیرمجاز، حفظ مقدار دقیق scope و رد encoding خراب اضافه شده است.
بیلد تولید نیز موفق بوده است.
این بررسی با تست محلی انجام شده؛ درخواست زندهٔ Autodesk با حساب شما در این محیط اجرا نشده است.
