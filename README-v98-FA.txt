Ventra v98 — نرده تراس شیشه‌ای مدرن

این یک پچ کوچک افزایشی است و باید روی نسخه v97 نصب شود. مدل‌های مبلمان و گیاه قبلی در این ZIP تکرار نشده‌اند.

تغییرات نمایشی:
- نرده میله‌ای ساده به پنل‌های شیشه‌ای با پایه فلزی باریک تبدیل شده است.
- دست‌انداز گرد، صفحه پایه، پیچ‌های اتصال و بست‌های شیشه اضافه شده‌اند.
- پایه مشترک در گوشه‌ها دوباره ساخته نمی‌شود تا هندسه روی هم قرار نگیرد.
- دسکتاپ از متریال فیزیکی شیشه استفاده می‌کند؛ موبایل مسیر شیشه شفاف سبک‌تر را دارد.
- مسیر و ارتفاع ثبت‌شده نرده حفظ می‌شود؛ پلان، محل تراس و BOQ تغییر نمی‌کند.
- این سبک پیش‌فرض نمایشی برای wall.type = railing است و گواه مشخصات یا ایمنی اجرایی نرده نیست.

نصب:
فایل‌های ZIP را با حفظ مسیر روی ریشه ventra جایگزین کن.
مدل ذخیره‌شده را دوباره در 3D باز کن؛ تحلیل مجدد لازم نیست.
برای انتشار، npm run build سپس commit و push کن.
SQL، env، مدل دانلودی یا وابستگی جدید نیاز نیست.

اعتبارسنجی:
480 تست و production build پاس شد.
رندر واقعی WebGL دسکتاپ و موبایل و خروجی JPEG بررسی شد.
ارتفاع، اجزای پنل و پایه، ثابت ماندن داده ورودی و یکتایی پایه گوشه تست شد.
